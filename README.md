# Сайт-портфолио Марии Правосудовой

Открыть локально: двойной клик по `index.html` (видео и картинки лежат в `media/`).
Английская версия — `en.html`, переключатель RU / EN в шапке. Если правишь текст в `index.html`, поправь то же место и в `en.html`.

## Добавить цифры результатов (по желанию)
В разборах креативов после шкалы можно вставить абзац с результатом: сколько крутился креатив, CTR, hook rate или фидбэк баера.

## Убрать работу
Статика: удали её строку в массиве `ST` в index.html. Видео: удали блок `vcard`.

## Публикация на GitHub Pages (как «Хякки»)
1. Создай репозиторий, например `portfolio`, и загрузи туда содержимое этой папки.
2. Settings → Pages → Deploy from branch → main, папка / (root).
3. Сайт будет на https://mprav-cld.github.io/portfolio/

Резюме для скачивания: `files/Pravosudova_Maria_CV_RU.pdf` (русская версия сайта) и `files/Pravosudova_Maria_CV_EN.pdf` (английская). Замени файл с тем же именем, если обновишь CV.
